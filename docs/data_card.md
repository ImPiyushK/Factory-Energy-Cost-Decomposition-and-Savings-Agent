# Data card — synthetic generated dataset

dataset: generated by `scripts/generate_synthetic.py --seed 42` (deterministic;
NOT official hackathon data; committed for reproducibility).
Structured card: `data/synthetic/data_card.json` (also copied to `data/data_card.json`).

## Files & shapes
| file | rows | notes |
|---|---|---|
| meter_15min.csv | 158,120 emitted | MAIN is a cumulative counter (with a reset on 2026-07-15 02:00); 8 sub-meters are interval kWh; ~0.3% missing intervals (plus one 8-hour gap on furnace_1) and 5 duplicate rows are deliberately present |
| tariff.csv | 10 rows | TOU peak/shoulder/off-peak; mid-Q3 change effective 2026-07-20 (0.24→0.36 peak) |
| production.csv | 549 rows | products A/B/C daily volumes; Q2 mean mix .40/.35/.25 → Q3 .52/.30/.18 (with realistic daily jitter); volume +5% in Q3; 2-shift weekday pattern, Saturday half-shift |
| weather.csv | 183 rows | daily temperature + CDD/HDD at base 18°C; heatwave 2026-08-10..20 |

## Injected ground truth (declared because this is OUR data)
* compressor leak: constant **+9 kW** on `compressors_2` from 2026-08-10 (full-year
  potential 9 kW × 8760 h = **78,840 kWh/yr**) — the "hidden waste pattern".
* public holiday **2026-08-15 logged as a normal shift** (edge case); 2026-05-01 is
  correctly marked.
* sub-meters sum to ≈ **96.5%** of main (coverage drift within the ±5% tolerance).
* emission factor for the analysis: **0.42 kg CO2e/kWh** (declared in the card, as a
  data pack would).
* a second dataset WITHOUT the leak exists: `data/eval/no_leak/` (--seed 7,
  --no-leak) used by the evaluation set to prove the system does NOT claim waste
  when tariff+mix explain the change.

## Reproduction
```bash
python scripts/generate_synthetic.py --seed 42 --out data/synthetic
python scripts/generate_synthetic.py --seed 7 --no-leak --out data/eval/no_leak
```
Ground-truth file: `data/synthetic/ground_truth.json` (read ONLY by the evaluation
harness, never by the analysis system).
